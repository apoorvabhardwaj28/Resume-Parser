# Resume Parser using NLP

A basic **Resume Parsing system** that automatically extracts important information from resumes using **Natural Language Processing (NLP)** techniques.

The application is deployed using **Streamlit**, allowing users to upload resumes and view extracted information through a simple web interface.

---

## Overview

Recruiters often need to manually review large numbers of resumes, which can be time-consuming. Resume parsing helps automate this process by extracting key details from resumes such as:

- Name
- Skills
- Education
- Work Experience
- Contact Information

This project demonstrates a simple **NLP-based approach for extracting structured information from unstructured resume text**.

---

## Features

- Upload resumes in text/PDF format
- Automatic extraction of resume information
- NLP-based text preprocessing
- Skill extraction from resume content
- Interactive web interface using Streamlit

---

## Methodology

The system follows these main steps:

### 1. Resume Upload
Users upload a resume through the Streamlit web interface.

### 2. Text Extraction
Resume content is converted into plain text for processing.

### 3. NLP Preprocessing
The text is cleaned and processed using NLP techniques including:

- Tokenization
- Stopword removal
- Text normalization

### 4. Information Extraction
Important resume entities such as **skills, education, and experience** are extracted using rule-based NLP methods.
